Reusable PHP platform powered by JB Framework: combines a REST API and MVC frontend with a CRUD module builder, business rules, state workflows, permissions, auditing and PDF generation.

Variables acuícolasAquaculture monitoring

Reemplaza la libreta de campo de productores y técnicos del Istmo de Tehuantepec. Junto al estanque se capturan temperatura (°C), oxígeno disuelto (mg/L), pH y turbidez (NTU); la app avisa si un valor está fuera de rango y muestra la tendencia de cada estanque. Replaces the field notebook of fish farmers and technicians in the Isthmus of Tehuantepec. At the pond they record temperature (°C), dissolved oxygen (mg/L), pH and turbidity (NTU); the app flags out-of-range values and shows each pond's trend.

  • Tres roles con pantallas distintas: administrador, técnico y productor.Three roles with different screens: administrator, technician and farmer.
  • Formulario generado desde el catálogo de variables del servidor, con rango orientativo y última lectura.Form generated from the server's variable catalog, with reference ranges and the last reading.
  • Guardado de toda la visita en una sola transacción (todo o nada).The whole visit is saved in a single transaction (all or nothing).
  • Estadísticas a 7, 30 y 90 días con gráficas de tendencia; tema claro y oscuro.7, 30 and 90-day statistics with trend charts; light and dark themes.
  • API Laravel 10 con Sanctum y pruebas de integración para autenticación, permisos, validación y captura en lote.Laravel 10 API with Sanctum and integration tests for authentication, permissions, validation and batch capture.

final class InscripcionService extends BaseService
{
    public function inscribir(int $estudiante, int $grupo): ServiceResult
    {
        if ($this->grupos->sinCupo($grupo)) {
            return ServiceResult::fail('El grupo no tiene cupo', 'SIN_CUPO');
        }
        $id = $this->inscripciones->crear($estudiante, $grupo);
        return ServiceResult::success('Inscripción registrada', ['id' => $id]);
    }
}
