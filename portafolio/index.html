Reusable PHP platform powered by JB Framework: combines a REST API and MVC frontend with a CRUD module builder, a dashboard builder, a public page builder, business rules, state workflows, permissions, auditing and PDF generation.

El retoThe challenge
Cada sistema nuevo repetía el mismo trabajo: listados, formularios, permisos, validaciones y auditoría programados a mano para cada tabla.Every new system repeated the same work: listings, forms, permissions, validations and auditing hand-coded for each table.
Lo distintivoWhat stands out
El constructor /admin/constructor permite configurar módulos a partir de tablas existentes: formularios, relaciones, validaciones, reglas y permisos sin escribir un CRUD desde cero; el constructor de tableros /admin/tableros arma indicadores y gráficas sobre esos módulos sin escribir SQL.The /admin/constructor builder configures modules from existing tables: forms, relations, validations, rules and permissions without writing CRUD code from scratch; the /admin/tableros dashboard builder composes indicators and charts on those modules without writing SQL.

    public function inscribir(int $estudiante, int $grupo): ServiceResult
    {
        if ($this->grupos->sinCupo($grupo)) {
            return ServiceResult::fail('El grupo no tiene cupo', 'SIN_CUPO');
        }
        $id = $this->inscripciones->crear($estudiante, $grupo);

    }
}
