# jbflores24.github.io

- `/` — sitio personal (inicio, servicios, perfil, académico), bilingüe.
- `/portafolio/` — portafolio de proyectos con capturas.

## Selección del portafolio

- **Código público principal:** `apiVariables` (Laravel), `jb-framework` (arquitectura PHP) y `jb-framework-ejemplo_ecommerce` (aplicación de demostración).
- **Evidencia complementaria:** `jbtest` y `pruebas_jb`, enlazados desde el framework por su propósito experimental.
- **Casos con código privado:** Lenguas, pitIA y plantilla de sistemas. Las capturas no se presentan como acceso público a su implementación.
- **Caso secundario:** credencial QR, conservado como ejemplo de interfaz institucional.

La selección cambia la presentación del sitio; no elimina repositorios ni modifica su visibilidad. Se mantienen las versiones española e inglesa y la disponibilidad para colaboración remota por proyecto o a tiempo parcial.
